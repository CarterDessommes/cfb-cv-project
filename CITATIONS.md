# Citations

This document contains citations for all major libraries and models used in this project.

## Deep Learning Frameworks

### PyTorch

Paszke, A., Gross, S., Massa, F., Lerer, A., Bradbury, J., Chanan, G., ... & Chintala, S. (2019). PyTorch: An imperative style, high-performance deep learning library. *Advances in Neural Information Processing Systems*, 32.

- Repository: https://github.com/pytorch/pytorch
- Documentation: https://pytorch.org/docs/

### Torchvision

Marcel, S., & Rodriguez, Y. (2010). Torchvision the machine-vision package of torch. *Proceedings of the 18th ACM International Conference on Multimedia*, 1485-1488.

- Repository: https://github.com/pytorch/vision
- Documentation: https://pytorch.org/vision/
